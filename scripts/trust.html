Trust this Synapse server

Synapse uses its own security certificate, because it's on a home network without a domain name. Tell this device to trust it once, and you'll get a secure connection with no warnings, plus offline mode.

  4. Use Chrome to open Synapse.
  1. Download the certificate and open synapse-ca.crt.

  3. Choose Place all certificates in the following store, click Browse, and pick Trusted Root Certification Authorities.
  4. Click Next, then Finish, then restart your browser.

Always use the address with the numbers (). The certificate is made for that address.

Why is this needed? A public certificate authority can't vouch for an address that only exists on your home network, so this server has its own. Installing its certificate tells your device to trust it. It only applies to this Synapse server.
